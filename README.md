# 간트 차트 웹앱

Node.js + Express 백엔드와 순수 HTML/CSS/JS 프론트엔드로 만드는 간트 차트 웹앱입니다.
프론트엔드와 백엔드를 동일한 Express 서버가 함께 서빙합니다.

> ## 📖 처음 쓰시나요? → **[사용법 안내서 (사용법.md)](사용법.md)**
>
> 간트 차트를 한 번도 써본 적 없는 분도 따라 할 수 있도록, 프로그램 여는 법부터
> 일정 만들기·마우스로 편집하기·엑셀/PNG/PPT 내보내기까지 그림과 함께 정리했습니다.
>
> 아래 내용은 **개발자·관리자용 기술 문서**입니다.

## 특징
- 백엔드: Node.js + Express
- 프론트엔드: 순수 HTML/CSS/JS (빌드 도구 없음)
- 서버는 `127.0.0.1` 에만 바인딩 (비공개 구조, 운영 시 SSH 터널로만 접근)
- 앱 자체 로그인 기능 없음
- 데이터는 JSON 파일로 저장 (원자적 쓰기)

## 로컬 실행법

```bash
# 1. 의존성 설치
npm install

# 2. 서버 실행
npm start
```

실행 후 브라우저에서 접속:

```
http://127.0.0.1:3000
```

- 헬스체크: `http://127.0.0.1:3000/health`
- 로컬 개발 데이터는 `./dev-data/` 에 저장됩니다 (git 제외).

### 환경 변수
| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | `127.0.0.1` | 바인딩 주소 (변경 금지 권장) |
| `DATA_DIR` | `<프로젝트>/dev-data` | 데이터 저장 경로 (운영: `/home/ubuntu/gantt-data`) |

## 프로젝트·태스크 관리 (CRUD)

우측 상단 툴바의 버튼으로 프로젝트와 태스크를 관리합니다.

- **+ 프로젝트 / + 태스크**: 우측 슬라이드 패널에서 폼을 작성해 생성합니다.
  (프로젝트가 하나도 없으면 "+ 태스크" 버튼은 비활성화됩니다.)
- **수정**: 좌측 목록에서 태스크 행을 클릭하면 수정 패널이 열립니다.
  프로젝트 그룹 헤더에 마우스를 올리면 나타나는 ✎(수정)·🗑(삭제) 아이콘,
  태스크 행에 마우스를 올리면 나타나는 🗑(삭제) 아이콘으로 각각 수정·삭제할 수 있습니다.
- **삭제**: 브라우저 기본 대화상자 대신 앱 내 확인 모달로 안내합니다.
  (프로젝트 삭제 시 소속 태스크 수, 태스크 삭제 시 하위 태스크 수를 함께 표시)
- 패널은 X 버튼, 배경 클릭, 또는 `Esc` 키로 닫을 수 있습니다.

### 업무 프로젝트 안내문에 대하여

프로젝트 분류를 **업무**로 선택하면 폼에 노란색 안내 박스가 표시됩니다.
이 안내문은 기관명·시험코드·대상자 정보 등 식별 가능한 정보를 입력하지 말고
`Site-A`, `Study-1` 같은 코드로 입력하도록 돕기 위한 **리마인더**입니다.

> ⚠️ 이 안내문은 **기술적으로 강제되는 제약이 아닙니다.** 서버는 입력값의 내용을
> 검사하거나 차단하지 않으며, 실제로 식별 정보를 입력해도 저장은 이루어집니다.
> 민감정보 보호는 전적으로 사용자의 판단과 주의에 달려 있습니다.

## 태스크 상태 체계

태스크 상태는 다음 5종입니다. 화면에는 영문+한국어를 병기하며, 상태별로 바 색이 다릅니다.

| 값 | 표시 | 색 |
| --- | --- | --- |
| `plan` | Plan (계획) | 회색 `#9ca3af` |
| `setup` | Set up (준비) | 보라 `#8b5cf6` |
| `ongoing` | Ongoing (진행) | 파랑 `#3b82f6` |
| `complete` | Complete (완료) | 초록 `#22c55e` |
| `delayed` | Delayed (지연) | 빨강 `#ef4444` |

- 기본값은 `plan` 입니다.
- **자동 마이그레이션**: 서버 시작 시 기존 데이터의 옛 상태값을 자동 변환합니다
  (`todo→plan`, `doing→ongoing`, `done→complete`, `hold→delayed`). 변환이 발생하면
  콘솔에 변환 내역이 한국어로 출력됩니다.

## 시각 요소 (5단계)

- **상태별 바 색**: 위 표의 색을 바·마일스톤 다이아몬드·좌측 목록의 상태 점에 적용합니다.
- **진행률 바**: 바 내부에 진행률만큼 더 진한 톤으로 채우고 "NN%" 텍스트를 표시합니다
  (바가 좁으면 생략). `complete` 는 100% 로 취급합니다.
- **우선순위**: 바 왼쪽 세로 띠(높음=진한 주황·두껍게, 낮음=연회색·얇게, 보통=없음)와
  좌측 목록 배지(높음/낮음)로 표시합니다.
- **자동 지연 경고**: 종료일이 오늘보다 이전인데 상태가 `complete` 가 아니면
  바에 빨간 점선 테두리와 좌측 목록에 ⚠ 아이콘을 표시합니다. (상태를 자동 변경하지는 않습니다.)
- **상태 범례**: 툴바 아래에 5색 범례를 표시합니다.
- **표시 토글**: 툴바 "표시 ▾" 에서 진행률·우선순위·지연 경고·범례를 개별로 켜고 끌 수 있으며,
  설정은 브라우저 `localStorage` 에 저장됩니다.

## 엑셀 내보내기/가져오기 (9단계)

툴바의 **내보내기 ▾** 드롭다운에서 사용합니다.
(같은 드롭다운에 `PNG 저장`·`PPTX 저장`도 함께 있습니다.)

### 내보내기
- 파일명: `간트차트_YYYY-MM-DD.xlsx`
- 컬럼(고정 순서): 프로젝트명, 구분, 태스크명, 상위태스크, 담당자, 시작일, 종료일,
  진행률, 상태, 우선순위, 마일스톤, 메모
- 화면 좌측 목록과 동일한 순서(프로젝트 → 계층)로 정렬됩니다.
- 보고용 서식: 헤더 굵게 + 연한 파랑 배경(#DCE6F1) + 전 셀 얇은 테두리,
  열 너비 자동(한글 2배 폭 감안, 최소 8·최대 40), 첫 행 틀 고정.

### 가져오기
- `.xlsx` 파일 선택 → **미리보기 모달**에서 추가될 프로젝트/태스크 수와
  행 단위 미리보기(처음 20행), 행별 오류 목록을 확인한 뒤 반영합니다.
- 오류가 있으면 "반영" 버튼이 비활성화되며, **오류 행을 제외하고 반영**을
  체크하면 정상 행만 반영할 수 있습니다.
- 반영 방식(추가 병합): 프로젝트명+구분이 기존과 일치하면 그 프로젝트에 태스크를
  추가하고, 없으면 프로젝트를 새로 만듭니다. 태스크는 전부 새로 추가되며
  기존 태스크를 갱신하지 않습니다.
- **중복 제외**: 반영 대상 프로젝트 안에 태스크명+상위태스크가 모두 같은 태스크가
  이미 있으면(같은 파일 안에서 같은 조합이 반복되는 경우 포함) 그 행은 오류가 아니라
  "중복(제외)"로 표시되고 자동으로 건너뜁니다. 중복 행을 상위태스크로 참조하는
  자식 행은 기존의 동일 태스크에 연결되어 정상 반영됩니다.
- 관대한 파싱: 상태는 `Plan (계획)`/`plan`/`계획` 모두 허용(우선순위·구분 동일),
  마일스톤은 `O`/`o`/`TRUE`/`예`/`1` 허용, 날짜는 엑셀 date 셀(일련번호)도
  YYYY-MM-DD 로 변환, 진행률은 `50%`/`50` 모두 허용, 빈 행은 무시합니다.

  (`public/js/export.js` 의 `injectFreezePane`/`zipStoreEntries`).

## PNG / PPTX 내보내기 (10~11단계)

- **PNG 저장**: 차트 전체를 이미지로 저장. 캔버스 한계(16,384px)를 넘으면 배율을 자동으로
  낮추고, 그래도 넘으면 기간을 나눠 여러 장으로 저장합니다.
- **PPTX 저장**: 선택 창에서 4가지를 고릅니다.
  - 범위: 전체 / 선택한 프로젝트
  - 차트 표현: `이미지`(html2canvas 캡처, 웹 화면과 동일) / `도형`(PptxGenJS 네이티브 도형,
    편집 가능·이미지 의존 없음)
  - 슬라이드 레이아웃: `프로젝트당 1슬라이드` / `긴 프로젝트는 기간 분할`
  - 태스크 목록 표 포함 (체크박스)
- 캡처 계열(PNG·PPTX 이미지 방식)은 `public/js/export-capture.js` 의 공용 옵션을 사용합니다.
  html2canvas `onclone` 단계에서 현재 페이지의 스타일 규칙을 복제 문서에 직접 주입하므로,
  스타일시트 재요청 실패와 무관하게 항상 정상 렌더되며 다크모드와 상관없이 라이트 톤으로 출력됩니다.

## 배포 참고

`ecosystem.config.js` 는 PM2 로 운영할 때 쓰는 설정 예시입니다.

```bash
pm2 startOrRestart ecosystem.config.js --env production
```

`DATA_DIR` 를 저장소 바깥 경로로 지정하면 `git pull` 이 데이터를 건드리지 않습니다.
서버는 `127.0.0.1` 에만 바인딩되므로 외부 노출 없이 SSH 터널로만 접근하는 구성을 권장합니다.
(방화벽에서 앱 포트를 열지 마세요.)
